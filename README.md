# Pizza Italie

Bilingual (FR/EN) one-page site for **Pizza Italie** — Hull’s late-night pizzeria at 101 Promenade du Portage, Gatineau, open since 1995.

- Pickup & delivery via OlivePOS
- Menu grid, reviews, hours (16:00–04:00 America/Toronto), map
- Language toggle persists in the browser

## Stack

React 19, TanStack Start, Tailwind CSS v4

## Scripts

```bash
npm install
npm run dev
npm run build
```
